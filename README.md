# quotes-scraper
A python based code that scrapes quotes from a website and saves it in a text file along with the name of the authors. The python code uses beautifulsoup4 and requests libraries to scrape through website efficiently. 
#Libraries Used 
-requests
-beautifulsoup4
#How to Run
1.Install libraries: pip install requests beautifulsoup4
2.Run: python code-scraper.py
3. Output saved to quotes.txt
